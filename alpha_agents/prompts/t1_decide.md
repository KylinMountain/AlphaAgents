- **换手%** 告诉你这只票今天有多活跃，也间接告诉你盘子大小。换手 20% 的

- **连板** 是它上一交易日是第几个涨停（空白 = 当天没涨停）。**这是 A 股最
  重要的情绪指标**：首板是启动，二三板是加速，高位连板是接力风险。同一个
  9% 涨幅，首板和第五板的含义完全相反。
- **主力净额(万)** 是上一交易日主力资金的净流入（正=流入，负=流出，空白=
  该日未归档）。**价格是结果，资金是原因**：一只票放量上涨且主力净流入，
  和同样涨幅但主力净流出（散户抬轿），后续走势通常不同。
- **概念** 是这只票的板块归属。**A 股是板块驱动的**：一只票脱离主线独自
  上涨，通常是一日游；主线启动时的跟风票，才有连续性。如果候选里多只票
  同属一个概念，那通常说明这条线今天是热的——这比单看个股涨幅有信息量。

## 你要输出什么

只输出一个 JSON 对象，不要解释、不要 markdown 围栏：

{{
  "orders": [
    {{
      "code": "600000",
      "entry_low": 10.20,
      "entry_high": 10.45,
      "stop_loss": 9.60,
      "target_price": 12.00,
      "reason": "一句话，说明为什么是这只、为什么是这个价位"
    }}
  ]
}}

规则：

- 最多下 **{picks}** 单。**可以不下单**——`{{"orders": []}}` 是合法回答。
  没有值得买的就空仓，不要为了下单而下单。
- `code` 必须逐字出现在上面的候选池里。
- `entry_low` < `entry_high`，且 `stop_loss` < `entry_low`。
  挂单价是限价：今天开盘价必须落在 `[entry_low, entry_high]` 里才会成交。
- `target_price` **强烈建议给**，且必须 `> entry_high`：这是你打算在哪里止盈。
  不给的话这个仓位就只剩止损一条出路。**止损距离和止盈距离一起决定赔率，
  只写止损等于只写了一半。** 目标要和你的理由一致——理由是"主线启动、
  资金流入"，目标就该对应那条线通常能走的空间，而不是"涨 3% 就跑"。
- **止损距离要比这只票的日常波动宽。** 参考 T-1 涨幅和 ADV20 判断它的
  波动幅度；止损比日均波动还窄，你会被正常噪音打出去。本仓库第一次
  20 天回放的 11 笔交易**全部止损出场**，止损中位距离只有日均波动的 1.3 倍。
- `reason` 里说清你**看到了什么**（价格形态 / 资金 / 消息），不要写空话。
