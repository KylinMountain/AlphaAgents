# 没有系统出场线：止损止盈只来自 agent 自己

状态：active
创建：2026-09-26

## 目标

用户 2026-09-26 的方向："直接把硬止损、硬止盈这条去了，要加也是 agent 自己觉得需要加。"

此前实盘（`AGENT_EXIT_DECISIONS=1`）有两条 agent 不能否决的系统线：成本亏损达
`HARD_STOP_PCT`（8%）和主线归档；买入决策又**必须**写 `stop_loss`。回放默认则把入场
止损/止盈价机械执行。这些都是系统替交易员做的出场决定，平仓结果衡量的是规则，不是
交易员，学习因此不可归因。

改为：

- 系统不再有任何自带的出场线（删除 `_is_hard_exit` 的 8% 与主线归档两条）。
- `stop_loss` 与 `target_price` 在买入决策里都是**可选**的。agent 写了，就是它自己下的
  挂单，由代码确定性执行（模型宕机也照样执行）；没写，就没有，只有 agent 自己能卖。
- 系统的移动止损、看空收紧、主线走弱、持有期上限只作为信号交给 agent，不平仓。
- 实盘与回放同一口径：`--live-exits` 即"agent 决定卖出 + 执行 agent 自设价位 + 无系统线"。

`HARD_STOP_PCT` 仍被 `risk_budget_sizing`（默认关闭）当作定仓时的最小风险距离；那是
定仓假设，不是出场，本次不动，只把设置页的说明改对。

## 验收

- [ ] `t1_decider` 接受不带 `stop_loss` 的订单；带了则仍须低于入场价。测试覆盖两种。
- [ ] `position_monitor.check_positions(hard_only=True)`：成本亏 20% 且无自设止损 → 不平仓、
  发 signal；跌破自设止损 → 平仓；触及自设止盈 → 平仓；移动止损触发但未破自设止损 →
  只发 signal。测试覆盖四种。
- [ ] 主线归档不再强制平仓（测试）。
- [ ] 卖出提示词不再出现"硬线 / -8% 兜底"，而是列出每个持仓自设的止损/止盈（或"未设"）。
- [ ] 回放 `--live-exits`：自设价位执行并在报告里记为「自设止损 / 自设止盈」；
  没有自设价位的持仓只有 agent 能卖。测试覆盖。
- [ ] 全量测试、`lint_harness`、`lint_docs` 通过。
- [ ] 3 日真实模型 `--live-exits` 回放退出 0，报告出场归因里无系统线平仓；记录有多少
  订单自设了止损（只记录，不作为好坏判断，n 太小）。

## 决策记录

- 2026-09-26：自设止损执行，而不是只当信号。只当信号的话"agent 自己加止损"没有任何
  效果；执行它又保留了设计 §15"LLM 不可用时确定性保护仍在"——受保护的是 agent 自己
  声明过的线，而不是系统替它定的线。
- 2026-09-26：读 `initial_stop_loss`（成交时写入、之后不变），不读 `stop_loss` 列：后者会
  被移动止损和看空收紧改写，那是系统规则的输出，不是 agent 的挂单。
- 2026-09-26：风险：没有系统兜底，agent 不设止损又不卖，模拟账户可以单票亏到底。这是
  用户明确选择的实验条件，账户为模拟盘；报告会列出无自设止损的持仓数与最大浮亏，
  让这个后果可见而不是被隐藏。
