# 没有止损，也没有止盈：卖出只由交易员决定

状态：active
创建：2026-09-26

## 目标

用户 2026-09-26："就是不要硬止损了，硬止盈了……让 agent 自己学吧。"

第一版（`7236a0c`）只删了系统的 8% 线和主线归档强平，却保留"agent 在订单上写的
止损/止盈照单执行"。被纠正：那仍是一个价位在替交易员卖。最终口径：

- **没有任何价位会卖出持仓**：没有 `HARD_STOP_PCT` 线、没有主线归档强平、没有订单
  止损单、没有止盈单。
- 买入决策（T1 / sector 交易计划 / 晨扫）不再要求、也不再使用 `stop_loss`、
  `target_price`；模型若仍写出，忽略而不拒单。
- 移动止损、看空收紧、主线走弱、持有期上限、失效条件照常计算，**只作为信号**唤醒
  交易员，不平仓。
- 卖出权固定交给交易员：`AGENT_EXIT_DECISIONS` 开关移除（关闭即"规则替它卖"，
  本身就是硬止损）。
- 回放：`--decider llm` 一律由 agent 卖出、不执行价位；`--autonomous`、`--agent-exits`、
  `--no-stop-loss`、`--no-take-profit` 仍可解析但对 llm 无效。只有 placeholder 决策器
  （无 agent 可问）保留机械价位。实验 runtime 契约记录实际生效值而非 argparse 值。
- 何时离场由交易员从自己被复盘的结果里学（逐笔复盘、守则、Lesson/Rule）。

`HARD_STOP_PCT` 仅剩 `risk_budget_sizing`（默认关闭）定仓时的风险距离，不触发卖出。

- [x] `t1_decider` 输出的订单 `stop_loss` / `target_price` 恒为 None，模型写出的价位
  （含曾会被拒的非法值）被忽略不拒单；提示词不含这两个字段。
- [x] 卖出提示词写明"没有止损也没有止盈"，不出现"硬线 / 系统强制平仓 / 自设价位"。
- [x] llm 回放：订单带着价位、次日跳空穿越止损，持仓仍不被卖出；agent 被询问且 HOLD

## 决策记录

- 2026-09-26：连 agent 自挂的止损/止盈也不执行。自动执行的价位让平仓结果衡量那个价位
  而非交易员的判断，学习不可归因；北极星是"会因亏钱而改变行为"，这需要亏损由它自己的
  决定造成、由它自己的复盘看见。
- 2026-09-26：风险：模型不可用时持仓不会被任何东西卖出，单票可以一直亏。这是用户明确
  选择的条件，账户为模拟盘；风险用报告让它可见，不用规则兜底。
- 2026-09-26：设计文档 §15 "禁用 LLM 不停止确定性风险保护"与此冲突；本决定以用户方向
  为准，TRADER_CORE_DESIGN 需同步修订该条（见下）。
