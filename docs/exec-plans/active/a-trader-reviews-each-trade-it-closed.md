# 每平仓一笔，交易员写一次逐笔复盘，并在之后每一次决策里读到

## 现状（2026-09-23，30 天默认交易员回放，前 16 个交易日）

- 回放里交易员唯一能读到的"经验"，是 `evidence.analyse` 用固定公式算出来的
  一句话：「T-1 涨幅高于中位数的 6 笔中位收益 −3.54%，低于的 7 笔 −1.35%」。
  这句话在 81 个提示词里出现过，但它下单时 T-1 涨超 3.7% 的比例从 7/13
  **升到了** 11/16。这句话里没有任何可以照着做的东西。
- 线上交易员**一条自己的经验都读不到**：决策提示词里的知识块只放经过批准的
  规则，而经过批准的规则一条都没有；15:30 复盘写的 `daily_lessons` 是整天的
  笼统感想，不是逐笔的，也不进入决策提示词。
- 最大的一个亏损来源，它从来没见过对应的数字：13 笔平仓平均峰值 +7.2%，
  实际到手 +0.4%，**吐回 6.8 个点**；7 笔的峰值出现在买入当天。

## 目标

每平仓一笔：

1. **代码**把这笔交易的事实算出来（买入理由、T-1 涨幅、持有期峰值及其出现
   在第几天、最大浮亏、卖出理由、到手收益、吐回的点数），数据截至平仓日。
2. **交易员自己**写复盘：做对了什么、错在哪、下次怎么做，必须引用上面的数字。
3. 复盘存进 `trade_reviews`，此后它的每一次决策（选股、下单、卖出）都会读到
   最近的复盘，外加一行由代码算出的汇总（平均峰值 / 平均到手 / 平均吐回 /
   峰值出现在买入当天的比例）。

它读到之后怎么改，由它自己决定。这里不加规矩。

## 不可越过的约束

- 数字由代码按 `daily_kline` 计算，并封在平仓日（GOLDEN_PRINCIPLES 第 2 条）。
  模型写的话里的数字不存进汇总。
- 复盘属于交易员"自己的记录"那一半（和持仓、校准曲线同类），不是
  `knowledge_in_force` 里需要批准的规则，所以不绕过审批机制。
- 固定公式的那句 T-1 统计仍然记在 `learning_candidates` 里，但不再进入提示词。

## 验收标准

1. `trade_review.facts()` 对一笔已知 K 线的交易，给出的峰值、峰值是第几天、
   吐回点数与手算一致（由测试钉住）。
2. 每平仓一笔都会产生一条复盘，无论是回放还是线上 15:30；同一个
   `position_id` 不会被写两次。
3. 模型报错或回复读不出来时，依然写下只含事实的那一行，汇总照样可以计算。
4. 回放第二天的决策提示词里包含前一天平仓那笔的复盘；复盘所用数据不晚于平仓日。
5. 线上的早盘和卖出决策提示词都包含这个复盘块。
6. pytest、lint_harness、lint_docs 全部通过。
