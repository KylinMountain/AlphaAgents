# v0.1.0 — 可信的交易事实，可归因的学习，可验证的进化

**Trade · Learn · Evolve** —— 一个 A 股模拟交易员。它交易，并且从自己的结果里学习。

这不是一个"更聪明的选股器"。它的交付顺序不可重排：

> **可信的交易事实 → 可归因的学习 → 可验证的进化**
>
> 一个从自己算不清的结果里学习的系统，学到的是自己的 bug。
> 更多的报告、更多的 agent，都替代不了这个顺序。

v0.1.0 是这个顺序的**第一个完整骨架**：事实层、学习层、进化层的机制都已落地并被测试钉住；
其中"进化"这一层**刻意停在门口**——机制可达，生产里一次真实晋升都没有发生。

## 一、可信的交易事实

| 能力 | 说明 |
|---|---|
| **现金反映累计结果** | 买入能力 = `本金 + 已实现净损益 − 在手持仓成本 − 挂单预留`。旧式读法把已实现损益排除在账户外：赚了钱的交易员花不掉利润，亏了钱的仍能花掉已不在的钱。 |
| **逐笔退出账本** | `position_exits`：每次减仓/清仓独立成腿，带原始指令快照。幂等键是调用方给的 `command_id`，**不是**"日期+价格+数量"——同日同价同量的两笔独立卖出是两笔指令，不是一次重试。 |
| **挂单必须可终结** | 每张挂单只有三种去向：成交、撤销、到期。资金在挂单成立时即被 `reservations` 预留，成交时按实际成本结算并**归还超预留**，撤销时全额释放。 |
| **T+1 结算批** | `settlement_lots` + `pending_settlements`：当日买入不可当日卖出；卖出款项当日**可用**、次日**可取**（A 股可用/可取分离）。 |
| **决策归属链** | `theses.id → virtual_portfolio.thesis_id → position_exits.thesis_id`，加 `episodes` / `episode_events`（`BEFORE UPDATE/DELETE` 触发器 `RAISE(ABORT)`，不可变）。事后把学习单元改指到另一个决策，是每一种事后归因偏差的形状。 |
| **三类结果各自独立** | `outcomes` 把一次决策拆成 **forecast**（判断对不对）、**trade**（赚没赚到）、**process**（过程合不合规）三个标签，append-only、带 `evaluator_version`。平仓**不得**重写预测标签；预测正确 ≠ 已实现盈利；程序违规不因赚钱而豁免。 |
| **决策时点冻结** | `decision_snapshots` 记录每个决策当时能看到什么。`replay_mode` 是一个全局 as-of 时间游标——回放里读"现在"的工具会拿到过去。 |

## 二、可归因的学习

- **一个决策一个 episode**，在业务规则跑之前落库。被拒绝的意图、撤单、形状不合法的意图都留下完整 episode；"进程死在动作中间"表现为指向 `submitted` 意图的事件，可查，不是空白。
- **候选知识有生命周期**：`learning_candidates` 五态 + `candidate_transitions`（append-only）。写入口 `save_candidate` 四个字段必填，`advance_candidate` 是 `status` 的唯一写者。
- **已批准知识快照**：`knowledge_snapshots` / `knowledge_snapshot_items`，写入口现算版本哈希，读侧只认**已批准快照**——一条 `active` 但从未进过批准快照的记录不生效。
- **观察会被写下来并引用**：回放/生产的学习步骤产出带日期的观察，注明样本量 n 与支持/反对证据。
- **小样本不进生产**：`GOLDEN_PRINCIPLES` §7 与晋升闸门现在是**同一个数**——`n < 20` 不晋升（2026-09-15 的 D15 把规则**降到 20 去就代码**，而不是把代码抬到 50；抬它会让所有已冻结版本立刻变 `drifted`）。所有候选目前停在 `observation`，管线**不驱动** `status`——"agent 学到了东西"在这里的含义是"写下了一条注明样本量的日期化笔记"，不是"行为变了"。

## 三、可验证的进化（机制可达，生产未跑）

```
候选知识 → 冻结候选版本 → 前向影子账户 → 独立评估（不退化才提交）
        → 人授权 → 切换 active policy → 回滚/退休（同样留痕）
```

- **版本注册表 + 在效指针**：`policy_versions` / `active_policy` / `policy_transitions` / `policy_approvals`。`freeze` / `install` 走同一个审计入口。
- **前向影子实验**：`shadow_runs` 按交易日推进，配对样本（同日同标的）比较，**只认候选诞生之后的日子**——候选是从最近几天蒸馏的，最近那段正是它拟合过的。
- **判据来自市场，不来自模型**：Brier 分数与因子残差，两个模型都碰不到的数字。不让模型给自己的记忆打分（模型把自己**错误的**记忆判为正确的概率是 31–54%，换个更强的裁判不解决，因为误差相关）。
- **不按累计收益判断一次改动**：年化 Sharpe 1.0 要约 4 年才能到 t=2；Brier 与残差几百个交易日就有功效。
- **可达 ≠ 在跑**：`evolve-lab` 会报 `reachable=True`，同时把"生产里一个版本都没有、一条实验都没跑"分开说——页面横幅专门为这件事存在。

## 四、回放与实验（这个版本的主要新增）

`scripts/walk_forward.py` + `scripts/walk_bootstrap.py`：一条 T+1 走前回放。

| 能力 | 说明 |
|---|---|
| **as-of 面板选股** | 决策日只能看到 T-1 及更早的日线与当日 09:00 前的快讯；面板是 T-1 涨幅榜，模型在面板内选。 |
| **结算判定四象限** | 一字板不成交、开盘越过区间但日内触碰记 `intraday_ambiguous`（日线无法判断谁先到），0 表示没遇到、不表示规则没生效。 |
| **一天两个决策** | 09:00 买入 + 14:55 收盘买入/卖出，**各有自己的信息边界与成交价**：开盘决策按开盘价成交，收盘决策按收盘价成交。混用就是未来函数。 |
| **agent 有卖出权** | `--agent-exits`：agent 对每个可卖持仓决定 hold / trim / add / sell，带理由。机械止损**先跑**，agent 只能看到幸存者——它无法用推理推翻风控硬线。 |
| **机械出场可分别关闭** | `--no-stop-loss` 与 `--no-take-profit` 独立开关，用来做"它不卖 vs 止盈在替它卖"的消融实验。两者全关且没开 `--agent-exits` 会被**拒绝运行**——那样没有任何东西能平仓。 |
| **模型调用全部留痕** | `llm_journal` 记录每次请求/响应（含 prompt 哈希），回放可复现；失败路径一律 **hold，不卖**（模型超时/报错/解析不出 = 不动仓位）。 |
| **生产库只读守卫** | 回放用 bootstrap 出的独立目录，报告里核对生产库内容哈希未变、语料只读。 |
| **报告如实** | 净值/回撤/超额（对比等权大盘）/成交/出场归因/挂单撤销原因/口径检查/决策器计数，外加一节**"本次运行不能说明什么"**。 |

## 五、工程约束（不靠自觉，靠构建失败）

```
data → sources → tools → evolution → pipeline → agents → server
```

- **分层方向**由 `scripts/lint_harness.py` 机械执法，反向 import 直接失败。
- **解析在边界**：每个外部 payload 先塑形再进业务逻辑。
- **文件 1200 行上限**、**结构化日志**（惰性格式化、可 grep）、**禁止裸 `except`**。
- **没有 LLM 给自己的输出打分**：记忆/原则/playbook 的效用只来自市场数据。
- **三态可区分**：三个工作台（`trade` / `learn` / `evolve`）渲染 `absent` / `partial` / `empty` / `present` 四种状态——`absent` 和 `empty` 在截图上长得一样，所以用 `npm run check:render` 的 3×3 渲染矩阵机械检查，每个用例同时断言"必须出现"和"**不得**出现"。

## 七、明确不做 / 尚未发生

这一节和上面同等重要。

- **生产里没有任何一次真实晋升**，也没有开过一次影子实验。机制已交付 ≠ 已经在跑。
- **历史回放不是时点模型回测**：今天的模型权重已经读过这些日期，所以回放只用于筛选候选、**从不晋升**。
- **回放的语料有已知缺口**：ST 状态取当前名而非当日名；容量（ADV20 占比）已测量、尚未强制；新闻只有免费快讯流。
- **回放里的 `{knowledge}` 块是本次运行自己的观察**，不是生产的检索路径（生产只经已批准快照）。
- **样本门槛**：`MIN_VALIDATION_SAMPLES = 20`（D15 于 2026-09-15 把规则**降到 20 去就代码**，不是把代码抬到 50——抬它会让所有已冻结版本立刻变 `drifted`）；所有观察停在 `observation`，晋升由人审批。

## 快速开始

```bash
git clone git@github.com:KylinMountain/AlphaAgents.git
cd AlphaAgents
uv sync
cp .env.example .env      # 配置 <ROLE>_API_KEY / _BASE_URL / _MODEL
uv run python main.py build-index
uv run python main.py run-v2
```

跑一次走前回放：

```bash
# 1. 造一个属于回放自己的数据目录（独立账本 + 共享只读语料）
uv run python scripts/walk_bootstrap.py --target /tmp/walk --corpus data

# 2. 跑窗口。--decider llm 走模型；--agent-exits 把卖出权交给 agent；
#    两个 --no-* 关闭机械止损/止盈（缺 --agent-exits 会被拒绝运行）
ALPHAAGENTS_DATA_DIR=/tmp/walk uv run python scripts/walk_forward.py \
    --start 2026-08-18 --days 20 --decider llm --agent-exits \
    --no-stop-loss --no-take-profit
```

报告写在 `/tmp/walk/run/`：`summary.txt` 是给人读的，`run.json` / `fills.csv` /
`equity.csv` / `settlement.csv` 是给机器读的。
