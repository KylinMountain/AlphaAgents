# 交易员的工具箱：从「找信号」到「会提问」

2026-09-10 设计。这份文档纠正的是一个方向性错误，错在我（AI 合伙人）身上，
所以先把错误写清楚。

## 一、我们差点走错的路

2026-09-10 一整天，我在做量化研究员的活：测某个信号有没有正期望。

用 7.7M 行日线跑了几组实测，结论都是负的：

| 检验的假设 | 样本 | 结果 |
|---|---|---|
| 放量（成交量 z>2）之后买入 | 45,866 | 后 5 日超额 **−0.21%**，胜率 43.1% |
| 巨量（z>4） | 14,165 | **−0.50%**，胜率 41.0% |
| 收盘位置区分「承接 / 派发」 | 45,866 | 三档无差别，方向还相反 |
| 板块热度日间持续性 | 3 天快照 | 资金前 10 **日间只重合 1/10** |
| 大涨股能否被新闻解释 | 25 只涨停 | 语义检索命中 92%，但真·前瞻催化剂 **不到 20%** |
| 涨停后的动量 | 13,953 | **+0.98% / 1日，+1.34% / 3日**，第 5 日衰减 |

然后我据此得出结论：「新闻驱动不成立、异动驱动不成立、主线驱动也不成立」。

**这个推理是错的。**

「放量后 5 日超额 −0.21%」的真实含义是：**「无脑买入所有放量股、闭眼持有
5 天」的平均值**。没有任何交易员会这样做。一条机械规则的负期望，恰恰是
**需要判断力的理由**，不是不该有判断力的证据。

我把「这个策略赢不赢」当成了「这件事能不能做」。

> **我们要养的不是一个信号，是一个交易员。**
> 正确的问题不是「怎么做成功率高」，是「**它有没有工具去做人做的那些事**」。

上面那张表因此保留在这里——不是作为「此路不通」的结论，而是作为
**「这些是机械规则的基线」**：agent 的判断如果不能打败这些数字，那它就
没有在真的判断。**它们是靶子，不是墓碑。**

## 二、数据不缺，缺的是提问方式

盘点了一下，短线交易员赖以为生的数据我们**几乎全都在存**：

| 数据 | 规模 | 用上了吗 |
|---|---|---|
| 涨停/跌停/炸板三池（含连板数、封单额、炸板次数、首封时间） | 10,041 条/3天 | ⚠️ 只当成一堆原始行丢给 agent |
| 全市场分时快照（每 5 分钟） | 558,112 条 | ❌ **从未用于任何日内决策** |
| 新闻向量索引 | 13,068 条 | ⚠️ 用于事后归因，不参与决策 |
| 日线 OHLCV | 7,740,919 条 | ⚠️ 只用来算价位，不用来认识一只票 |
| 板块资金流快照 | 146,213 条 | ⚠️ 只取前 20，跌出榜单就看不见（今日已修） |

**缺的不是数据，是「一个人类交易员会问的那些问题」还没有被表达成工具。**

真实交易员的经验，很大一部分就是**知道该问哪些问题**。我们给了 agent 一堆
原始行，指望它自己想出「炸板率」这个概念——它连问都问不出来。

## 三、一个交易员的一天：四类提问

### ① 今天这个方向能不能做

人会问：

- 昨天的涨停今天怎么样了？（**赚钱效应**——昨日涨停今日平均溢价）
- 连板梯队健不健康？4板/3板/2板各几个，有没有断层
- **炸板率**多少？（今天 10 炸 / 34 涨停 = 29%，说明承接弱）
- 首封时间早晚？9:25 一字 和 14:00 才封，是两种东西
- 最高板是几板？空间打开了没有

我们有什么：数据全在 `limit_pool_snapshots`，**但没有一个除法被做出来**。

### ② 入哪一只

人会问：

- 这个题材的**龙头**是谁，几板了
- **龙头断板了吗**——断板通常意味着这一波结束
- 我该买龙头、买跟风、还是买补涨？这是三种不同的风险收益
- 封单 9.18 亿 和 1.28 亿，哪个更稳
- 流通市值合不合适——太大拉不动，太小接不住

我们有什么：`consecutive_limits` + `seal_amount_yi` + `sector` 都在，
**但从未按题材聚合，也从未跨日跟踪龙头**。

### ③ 怎么做 T

人会问：

- 现在是冲高还是回踩？相对分时均价什么位置
- 早盘 30 分钟不动手；尾盘看承接
- 冲高卖一半，回踩接回来

我们有什么：`all_quote_snapshots` 每 5 分钟全市场，**55 万条，一次都没用于
日内决策**。系统对一天里的所有时刻一视同仁。

### ④ 什么时候退

人会问：

- 题材内部开始分化了吗（有的还在涨，有的已经跌）
- 龙头炸板了吗
- 昨天买的今天是溢价还是贴水
- 分歧转一致，还是一致转分歧

我们有什么：数据在，**没有一个被做成监控**。

## 四、还缺的（不止四类）

四类问题是「交易动作」。但一个交易员之所以像人，还有别的东西。

### ⑤ 状态：连输两次之后，人会收手

真实交易员有**手感**和**倾斜（tilt）**。连亏两笔之后要么收缩要么报复性交易，
这是最人性也最危险的部分。

我们现在：每笔独立决策，没有任何「今天已经错两次了」的概念。

要做的：把当日已实现盈亏、连续对错、当日决策次数喂进上下文，
**让 agent 自己决定要不要收手**——不是代码强制停手。收不收手本身
就是一个可以被复盘评价的判断。

### ⑥ 注意力：人只盯二三十只熟票

真实交易员不会每天扫 5000 只。他有一个自选池，反复做同几只，
**熟悉度会复利**——知道这只票的脾气、主力手法、习惯的振幅。

我们现在：每天每只票都是陌生人，永远在做第一次判断。

要做的：让 agent 维护自己的**关注池**，并且在看一只票时先看到
**「你以前怎么判断它的、结果如何」**。这是把熟悉度变成可检索的记忆。

### ⑦ 复盘：人重看那几笔，不是看统计

我们的复盘是聚合统计（胜率、校准曲线）。人的复盘是**重新走一遍那笔交易**：
当时我看到什么、我怎么想的、如果重来该怎么做。

我们有分钟快照——**可以真的重放当天的分时走势**。这个能力一次都没用过。

要做的：`replay_trade(position_id)`，把当时的分时、当时的涨停梯队、
当时的新闻还原出来，让 agent 重看一遍。**这才是复盘。**

### ⑧ 允许说「我不知道」

我们要求 agent 每个决策必须写理由。这比人强——人可以凭感觉。

但也有风险：**逼它编理由**。今天的实测里，25 只涨停有 4 只是
「交易所问询回复：未发生重大变化」——**连公司自己都说没原因**。
如果 agent 被迫为每次上涨编一个原因，它会学会编。

要做的：`skip` 时允许「不知道为什么，所以不做」作为一等公民的理由，
并且**统计它有多少次说不知道**——一个从不说不知道的交易员，不是自信，是没在思考。

### ⑨ 时间感

开盘半小时、盘中、尾盘、周五、长假前，行为应该不同。
系统现在对所有时刻一视同仁。

至少要让 agent **知道现在几点、离收盘还有多久**——它现在连这个都不知道。

## 五、工具清单与优先级

全部基于已有数据，**零新增抓取**。

| # | 工具 | 回答 | 依赖 |
|---|---|---|---|
| **1** | `get_limit_ladder()` | 今天能不能做 | limit_pool_snapshots |
| **2** | `get_theme_leader(theme)` | 入哪一只 | limit_pool + 板块 |
| **3** | `get_intraday_shape(code)` | 怎么做 T | all_quote_snapshots |
| **4** | `get_stock_memory(code)` | 我认识这只票吗 | theses + virtual_portfolio |
| **5** | `get_my_state()` | 今天手顺不顺 | 当日已平仓 + 决策记录 |
| **6** | `replay_trade(id)` | 那笔该怎么做 | 全部快照 |

前四个是**把人类的提问方式编码成工具**，后两个是**让它认识自己**。

## 六、这些怎么连回 Trade · Learn · Evolve

**Trade** — 工具让 agent 能做出人做的动作（做 T、留底仓、收手、只盯熟票），
而不只是「买入→等条件→卖出」。

**Learn** — 每个工具都对应一个**可证伪的判断**：
「今天梯队健康，可以做」→ 当天赚钱效应给出答案；
「这是龙头不是跟风」→ 明天断没断板给出答案。
判断进论点，结局进校准曲线。**工具的价值不在于它准，在于它让判断变得可评价。**

**Evolve** — 当某类判断的校准曲线足够好，它就该被写进 principles；
足够差，就该被 holdout_gate 淘汰。而不同交易员（`traders/*.yaml`）
可以有不同的提问偏好——有的重梯队，有的重题材，让它们比。

## 七、怎么知道它在变强

不看收益（噪声太大，见第一节的算术）。看三个：

1. **成交转化率** — 出手 → 真正走完一趟的比例。今天是 116 单 → 4 个结论（3.4%）
2. **校准曲线** — 它说 70% 的时候，实际兑现多少
3. **说「不知道」的比例** — 太低说明在编，太高说明没判断

三个都不需要几百笔交易，几十个已结论点就能读出来。

## 附：不要重走的路（今天已测）

- **不要**再找「能预测上涨的单一指标」。放量、位置、板块热度都测过了，
  在日线截面上没有正期望。基线胜率 45%，扣成本后更低。
- **不要**把威科夫的「建仓/承接/派发」搬到 1-3 天的题材行情上。
  那个框架预设主力用几周吸筹，而新闻驱动的行情里「主力」是
  9:31 买入、14:00 卖出的游资。**没有建仓阶段可以检测。**
- **不要**相信语义检索的高命中率。25 只涨停"命中"92%，实际
  八成是事后行情描述、交易所问询回复、或者完全误匹配。
- **可以**相信的一个基线：**涨停之后 1-3 天有动量**（+0.98% / +1.34% 超额，
  13,953 样本），第 5 天衰减。这意味着持有 5 天的默认设置本身值得质疑。
